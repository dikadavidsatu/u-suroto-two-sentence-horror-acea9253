Two-sentence horror story for make.fun's "Two-Sentence Horror" bounty. A single original story — the dentist said my son's adult teeth were coming in early, so we counted them together every night before bed. Tonight there were thirty-three, and he asked me which one of us gets to keep the extra. The program writes the story (200 characters, exactly two sentences) to `/output/entry.txt`, validating it against the competition gate (1–400 characters, not only whitespace, exactly two sentences) and reading it back to confirm exactly what was written.

## Run it

```sh
node main.ts
```
